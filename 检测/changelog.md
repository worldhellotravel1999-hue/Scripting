# 更新日志

## 1.0.0

### IP 查询与位置

- 在同一页面检测当前出口 IP，支持手动查询 IPv4、IPv6、复制地址、隐私显示、下拉刷新和返回当前出口。
- 汇集多源归属信息，按实际返回数据展示 ASN、运营商、所属机构、AS 域名、IP 主机名、IP 范围、网络属性及 ASN 人机流量比。
- 提供多源位置对照与可展开地图。地图默认收起，展开时与位置列表互斥；支持复制坐标和打开系统地图，位置仅供近似参考。

### 风险与系数

- 分别展示 IPPure 系数、经 IPPure 获取的 Cloudflare 系数及 proxycheck 风险，评分须与查询地址一致。
- IPPure、Cloudflare 两个系数分区分别按数据可用性显示：查询中、未取得评分、响应异常或地址不匹配时，整个对应分区隐藏；取得有效评分后在其保存位置显示，不留下标题、说明或空白排序项。
- 保留真实零分与缺失数据的区别。零分不绘制风险刻度，也不增加“0 分”提示；正分使用风险色条、气泡与刻度动画。
- 代理、VPN、Tor、匿名化、爬虫与受侵害标记仅在明确命中时显示，未命中或未知时不占位；按数据可用情况补充阳性置信度、设备估算及检出时间。

### 网络诊断

- 采集 WebRTC 候选地址，与对应地址族的 HTTP 出口对照，区分出口差异、数据不足、超时和不支持等状态。
- 展示本机网络接口、IPv4／IPv6、隧道观察、国内／国际 HTTP 响应耗时及 HTTP/3 观察，并补充国内探针出口对照。
- 检测 Netflix、Disney+、Spotify、TikTok、YouTube、Prime Video，以及 ChatGPT、Claude、Gemini、DeepSeek、Grok、Perplexity 共 12 项公开页面可访问性。
- 服务结果区分可访问、受限、失败与未知；公开页面可访问不代表订阅、播放、地区内容、模型或账户服务已解锁。
- 提供可选 Surge 快照与 HTTP API 接入，只采用有效且匹配当前出口的快照。设置提交或失焦后自动保存，密钥使用安全输入并仅保存在本机 Keychain。
- 手动查询指定 IP 时不混入手机当前网络与服务连通性结果。

### 页面与小组件

- 使用连续信息面板、统一图标按钮、青绿与蓝色配色，适配浅色和深色外观。
- 支持页面分区长按排序并保存顺序；暂时隐藏的分区保留完整顺序中的位置。采用兼容排序方案，绕开 iOS 27 原生排序的起拖断言路径。
- 提供小号、中号、大号与特大号小组件。默认展示 IP、归属、风险和网络诊断摘要，参数 `map` 可使用地图概览布局。
- 页面完成一轮检测后共享同轮 IP、归属、坐标、风险与网络诊断快照，小组件读取该结果并标注检测时间和过期状态。
- 点击小组件打开脚本重新检测；缓存有效期可设置为 5–240 分钟，默认 15 分钟，小组件实际重绘时间由 iOS 调度。
