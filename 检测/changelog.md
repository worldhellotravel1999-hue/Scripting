# 更新日志

本文档记录 IP检测 的主要版本更新。

## 未发布 - 2026-11-07

### 小组件与页面同步

- 页面每次检测完成后写入共享快照（当前 IP、归属、经纬度、风险、网络属性、风险标记）；小组件优先读取该快照，不再自己另查一份出口 IP，修复地图与 IP 停留在上一次查询的问题。
- 小组件风险优先使用 proxycheck，缺失时回退 IPPure；只有从未打开过页面、没有快照时才使用本地启发式，并明确标注“估算”。0 分不绘制刻度条，与页面规则一致。
- 检测完成与隐私切换后统一延迟 300ms 调用 `Widget.reloadUserWidgets()`，避开共享存储后台落盘，避免小组件读到上一份快照或旧隐私设置。
- 验证：快照构建、风险优先级、未标记/未知区分与坐标校验等 92 项回归断言通过；systemMedium 实际预览显示 8.8.8.8、Mountain View、风险 42%，确认使用快照而非实时自查。

### 风险标记精简与动效

- 代理、VPN、Tor、匿名化、爬虫、受侵害六类标记改为只渲染明确命中项；`false`、`null`、查询中与暂无数据不再生成“未标记/暂无数据”占位行，空结果时整区不占高度。
- 命中标记逐条弹入（透明度、位移、缩放、弹簧），标签外圈循环扫出同色光环；代理沿用 proxycheck 优先、ip-api 兜底，仍排在首位。
- 说明文案同步改为“仅列出已命中项，未列出可能是未命中或暂无数据”，避免把空行误解成安全结论。
- IPPure / Cloudflare / proxycheck 三个风险区为真实 0 分时均不再渲染刻度条，也不再显示“评分 0 分”文字；0 分视为无风险，不占位，只有评分缺失时才显示待获取状态。
- 验证：新增标记筛选与零分刻度条回归断言，83 项断言通过；全项目 TypeScript 诊断通过；命中、未命中与 0 分隐藏刻度条预览截图验证（`tests/preview-flags.tsx`）。

### 脚本审查与维护

- 修复零长度 `::` 压缩被当作合法 IPv6、带空白 IPv4 绕过隐私遮罩的问题；WebRTC 与 HTTP 出口共用地址归一化和公网范围判断，补充本地/保留/文档网段过滤及 NAT64 边界。
- 对 ip-api / ipwho.is 的字段做运行时收窄，防止异常字符串、布尔值及缺失字段导致界面或组件抛错。缺失坐标使用非有限值，不再补零画错地图；真实零经纬度与缺失区分。
- 允许归属源失败时继续显示已取得的同地址 proxycheck 信誉数据；位置未知不再丢弃已验证的 HTTP 出口地址。
- IPPure 网页风险增加独立地址校验；地址缺失或不匹配的分数不采信，官方 API 同址补分不变。WebView 创建纳入异常保护，网页失败不再连带丢失官方 API 回退。
- 为小组件地图等待增加 6 秒应用层预算，失败/超时退化为文字信息；增加顶层异常视图和页面入口退出兜底。此超时只停止等待，不是 MapKit 原生任务取消。
- 清理未使用的 `BAND_BG` 导入、中型小组件不可达的 ISP 分支与冗余条件、WebRTC 重复地址解析与分类实现；删除本次一次性网页探针。
- 验证：保留 `tests/regression.ts` 离线回归入口，76 项断言通过；全项目 TypeScript 诊断通过；手动 IP 单页和小号/中号小组件运行验证通过。本次未重新进行视觉截图验收。
- 外部限制：本次 IPPure 网页实测未获得成功风险对象，因此 `ipQuality.data.ip` 的成功响应契约仍待样本确认；缺乏同址证据时保持“未取得”，不借用其他地址的评分。ip-api 免费源仍为 HTTP，未擅自改成不支持的免费 HTTPS；小组件已改为优先读取页面共享快照，仅在无快照时使用启发式估算，见上方“小组件与页面同步”。

- 参考 NodeQuality / IPQuality 的基础信息与风险因子，直接增强现有单页：按需显示运营商、所属机构、IP 主机名，以及大洲、归属时区（含 UTC 偏移）、参考邮编；ASN 下方已有的网络名称自动去重。
- 扩展现有 proxycheck v3 响应解析，展示 VPN、Tor、匿名化、爬虫与受侵害标记；原三态展示已由上方“风险标记精简与动效”取代，未命中项不再占位。
- 在原 proxycheck 评分下补充阳性检测置信度、IP / 网段设备估算、首次及最近检出时间；设备数明确为数据库估算，记录时间使用 UTC，不合成新的风险分数。
- 沿用连续面板、统一标签列和色彩；地图默认收起及列表互斥逻辑保持不变。新增 IP 主机名随隐私模式隐藏；未增加二级界面或额外网络请求。
- 验证：21 项解析、零值、IPv6 同址、异常字段、时区与去重检查通过；真实接口查询通过；窄屏长文本、风险动画终点与完整单页原生截图验证通过。此次 8.8.8.8 实测 IPPure / Cloudflare 未返回同址评分，保留原有缺失状态。

- 修复 IPv4-mapped IPv6（如 `::ffff:192.0.2.1`）无法输入查询、隐私模式可能原样显示完整地址的问题；地址比较统一使用规范化结果，压缩写法与完整写法不再被误判为不同出口。
- 修复 VPN 接口检测仅识别 IPv4 地址、遗漏仅带 IPv6 地址的接口的问题。
- 修复 IPPure 出口地址使用自身比较作为有效性判断的无效逻辑，并容忍查询取消后重复释放 WebView。
- 清理未被页面或小组件消费的 `isNative`、`pinPoint`、`vpnConfidence`、`vpnMethod`、proxycheck 冗余信誉字段、位置行国家码及 IPPure 自身 IP 字段，删除一次性网络接口探针 `_probe.ts`。
- 验证：12 项地址解析 / 等价比较 / 隐私格式化边界测试通过；全项目 TypeScript 诊断通过。

## [1.7.0] - 2026-11-06
