# Report ip

IP 查询、风险与网络诊断融合在同一页面。页面完成一轮检测后，将 IP、归属、地图坐标、风险和网络报告保存为同一份共享快照，小组件读取这份结果。

## 页面新增能力

- 本机 Wi-Fi / 蜂窝等网络接口、IPv4 / IPv6、隧道接口观察。
- 国内探针的出口、归属和运营商并入原有 HTTP 出口对照。
- 国内与国际站点的 HTTP 响应耗时，取本轮成功请求最小值。
- Cloudflare trace 的 HTTP/3 观察。
- Netflix、Disney+、Spotify、TikTok、YouTube、Prime Video，以及 ChatGPT、Claude、Gemini、DeepSeek、Grok、Perplexity 共 12 项公开页面访问检测。
- 同页可选 Surge 设置：快照 URL、HTTP API 主机/端口、Keychain 保存的密钥。
- 长按页面分区可拖动排序，顺序会保存；手动查询时暂时隐藏的服务分区会保留各自的顺序。

多源归属、IP 查询、地图、proxycheck / IPPure / Cloudflare 风险、WebRTC 与隐私显示在同一页面。IPPure 和 Cloudflare 系数各自在取得同地址有效评分后才显示整区；未取得时不显示标题、说明或空白拖动项，保存顺序仍保留。真实 0 分属于有效数据，但不绘制刻度条或增加零分提示。没有新增第二套启发式纯净度评分。

服务状态区分可访问、受限、失败与未知。403、429、认证或验证码页面不算可访问；2xx 公开页面可访问不等于订阅、播放、地区内容或账户服务已解锁。HTTP 耗时包含建连等开销，不是 ICMP ping。所有本机请求遵循当前分流规则；未观测到 HTTP/3 不等于 UDP 被禁用。接口地址也不代表 NAT 类型或必然使用的出站路径。

## 小组件

打开脚本并完成一次当前出口检测后，在 Scripting 小组件中选择 Report ip。

- 大号与特大号：IP / 地图主区、三个横向诊断指标、两组服务列表、网络摘要和检测时间。
- 中号：IP、地图、归属、ASN、风险、服务计数和响应摘要。
- 小号：紧凑 IP / 地图、风险属性、服务计数、响应与检测时间。
- 所有尺寸共用青绿与蓝色配色、层级和状态语义，适配深浅色；背景使用系统兼容的 widgetBackground。
- 参数留空或填 `radar` 使用新设计。填 `map` 保留原地图概览布局。
- 点击小组件通过系统链接打开脚本，重新检测并写入同轮快照。没有快照时会提示打开脚本。

“有效期”默认 15 分钟，可设置 5–240 分钟，同时作为向 iOS 申请小组件重绘的间隔。过期数据明确显示已过期；重绘不会另查出口或伪造新检测时间，实际调度由 iOS 决定。手动查询 IP 时不附带手机当前网络结果。

## Surge 可选接入

只在填写 URL 后读取远端快照；只有保存密钥后才读取 HTTP API。文字输入按回车或离开输入框后自动保存，数字输入离开输入框后保存；错误输入保留草稿并显示原因。密钥在安全输入框中以圆点显示，输入后回车或离开输入框会保存；删空输入框会清除本机 Keychain 密钥并停用 API。密钥不会写入共享快照。

兼容网络诊断雷达的 Surge v1 快照。快照必须未过期且出口与当前查询一致；打码、异址或损坏快照回退本机检测。旧上游只有 `ok` 布尔值，缺乏 HTTP 状态证据时显示未知，并附上游说明。

API 策略标签只匹配本轮探测前基线之后的同域请求，过滤 QUIC-BLOCK。近期活跃节点不代表全部流量的唯一出口，不按节点名字猜服务地区；全部直连清空旧代理协议和策略。

- `tests/regression.ts`：IP、风险、评分分区显隐、WebRTC、地图与快照回归，102 项。
- `tests/network-regression.ts`：服务判定、接口、HTTP 协议、异常数据及手动/异址隔离，142 项。
- `tests/surge-regression.ts`：Surge 设置、快照、基线、策略和直连转换，91 项。
- `tests/module-order-regression.ts`：模块顺序上下移动、异常数据、手动模式及缺评分分区恢复，23 项。
- `tests/live-network.ts`：人工真实网络冒烟，不保存共享快照。
- `tests/preview-network.tsx`、`tests/preview-network-widget.tsx`：无网络的页面与小组件边界预览。
- `tests/preview-modules.tsx`：使用真实系数分区及兼容排序容器，顺序只存于预览内存；支持 `manual`、`risk`、`cloudflareRisk` 和模拟异步返回的 `resolve` 参数。
