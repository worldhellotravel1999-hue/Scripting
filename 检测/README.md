# Report ip

IP 查询、风险与网络诊断融合在同一页面。页面完成一轮检测后，将 IP、归属、地图坐标、风险和网络报告保存为同一份共享快照，小组件读取这份结果。

## 页面新增能力

- 网络测速已并入“网络诊断”分区，标题栏右侧的仪表按钮在与“本机诊断”之间切换（与位置分区的展开地图同构）；不再占用独立的可排序分区。切换后分区标题与图标同步变为“网络测速”或恢复“网络诊断”。测速进行中锁定切换，避免卸载中止后被误认为卡住。
- 位置分区展开地图后，标题由“位置”变为“地图”，图标换为地图图标并带一次轻微弹跳；返回列表时恢复“位置”与图钉图标。
- 测速面板主操作为图标按钮，与分区图标按钮同为 34×34：待开始蓝色播放键，进行中红色停止键。
- 本机 Wi-Fi / 蜂窝等网络接口、IPv4 / IPv6、隧道接口观察。
- 国内探针的出口、归属和运营商并入原有 HTTP 出口对照。
- 国内与国际站点的 HTTP 响应耗时，取本轮成功请求最小值。
- Cloudflare trace 的 HTTP/3 观察。
- Netflix、Disney+、Spotify、TikTok、YouTube、Prime Video，以及 ChatGPT、Claude、Gemini、DeepSeek、Grok、Perplexity 共 12 项公开页面访问检测。每项固定显示“地区码”：可用、受限、失败与未知状态都保留已观测的两位代码；本轮无证据时显示“未取得”。缺失服务结果也保留位置。
- 地区码附来源：Netflix 国家字段/站点路径；Disney+ 站点 `region`；Spotify 官方匿名 GET 配置的顶层 `country`；TikTok `VRegion` 服务区域；YouTube `INNERTUBE_CONTEXT_GL`（支持官方移动站跳转）；Prime Video `currentTerritory`；DeepSeek 页面 `meta region`；Grok 国家响应头；ChatGPT、Claude、Grok、Perplexity 可补充同域 trace 的 `loc`。Gemini 从 `WIZ_global_data.vXmutd` 读取页面区域，明确标注“页面区域”，不能视为独立 IP 国家证据。
- 同页可选 Surge 设置：快照 URL、HTTP API 主机/端口、Keychain 保存的密钥。
- 长按页面分区可拖动排序，顺序会保存；手动查询时暂时隐藏的服务分区会保留各自的顺序。旧顺序里的 `speed` 槽位会被自动忽略，其余分区相对顺序不变。

多源归属、IP 查询、地图、proxycheck / IPPure / Cloudflare 风险、WebRTC 与隐私显示在同一页面。IPPure 和 Cloudflare 系数各自在取得同地址有效评分后才显示整区；未取得时不显示标题、说明或空白拖动项，保存顺序仍保留。真实 0 分属于有效数据，但不绘制刻度条或增加零分提示。没有新增第二套启发式纯净度评分。

服务状态区分可访问、受限、失败与未知。地区代码来自服务响应或服务级快照 `cc`/`regionCode`，不根据总出口归属、节点名或策略名补猜。页面区域、匿名配置、服务路由区域与同域 CDN 观测含义不同；页面区域可受站点参数影响，均不证明账户地区、可播放内容或模型可用性。403、429、认证或验证码页面不算可访问。服务正文最多采样 1 MiB 解析地区，连通性判定最多检查前 200,000 字符，后面的限制文案可能无法识别；trace 最多 16 KiB，Spotify 配置最多 64 KiB。正文失败保留已取得的响应头地区；trace 需官方同域、正确路径、2xx 与 text/plain，补地区不会覆盖主页受限状态。HTTP 耗时包含建连等开销，不是 ICMP ping。所有本机请求遵循当前分流规则；未观测到 HTTP/3 不等于 UDP 被禁用。接口地址也不代表 NAT 类型或必然使用的出站路径。

## 小组件

打开脚本并完成一次当前出口检测后，在 Scripting 小组件中选择 Report ip。

- 大号与特大号：IP / 地图主区、三个横向诊断指标、两组服务列表、网络摘要和检测时间。
- 中号：IP、地图、归属、ASN、风险、服务计数和响应摘要。
- 小号：紧凑 IP / 地图、风险属性、服务计数、响应与检测时间。
- 所有尺寸共用青绿与蓝色配色、层级和状态语义，适配深浅色；背景使用系统兼容的 widgetBackground。大号与特大号的服务列表同步显示地区码并预留固定宽度；缺失显示“—”。中小号继续显示诊断摘要。
- 参数留空或填 `radar` 使用新设计。填 `map` 保留原地图概览布局。
- 点击小组件通过系统链接打开脚本，重新检测并写入同轮快照。没有快照时会提示打开脚本。

“有效期”默认 15 分钟，可设置 5–240 分钟；新鲜快照在实际过期时申请小组件重绘，过期或空快照按完整周期再申请。过期数据明确显示已过期；重绘不会另查出口或伪造新检测时间，实际调度由 iOS 决定。手动查询 IP 时不附带手机当前网络结果。

## Surge 可选接入

只在填写 URL 后读取远端快照；只有保存密钥后才读取 HTTP API。文字输入按回车或离开输入框后自动保存，数字输入离开输入框后保存；错误输入保留草稿并显示原因。密钥在安全输入框中以圆点显示，输入后回车或离开输入框会保存；删空输入框会清除本机 Keychain 密钥并停用 API。密钥不会写入共享快照。

兼容网络诊断雷达的 Surge v1 快照。快照必须未过期且出口与当前查询一致；打码、异址或损坏快照回退本机检测。旧上游只有 `ok` 布尔值，缺乏 HTTP 状态证据时显示未知，并附上游说明。

API 策略标签匹配探测前基线之后的同域请求，过滤 QUIC-BLOCK。标签标为“同期同域日志”，因为同域日志也可能来自其他应用。近期活跃节点不代表全部流量的唯一出口，不按节点名字猜服务地区；全部直连清空旧代理协议和策略。
